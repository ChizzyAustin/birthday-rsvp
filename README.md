# Birthday Thanksgiving · Studio Session — RSVP

RSVP page for Sunday, 18 October 2026, 3:30 to 6:00 PM at Blue Flame Media, Somolu, Lagos.

- **Live page:** https://chizzyaustin.github.io/birthday-rsvp/
- **Responses:** saved to a Google Sheet through a Google Apps Script web app (`apps-script/Code.gs`).
- **Capacity:** 35 guests. Invitations are personal (no plus-ones). When full, the form offers a waitlist.
- **Categories:** Family, Friends, Musicians, Special Guest.
- **Calendar:** `event.ics` for Apple/Outlook; the thank-you screen also links to Google Calendar.
- Re-submitting with the same WhatsApp number updates that guest's existing response.

To change the endpoint, edit `RSVP_ENDPOINT` near the bottom of `index.html`.
